# اصلاح صحت پیشرفت، گزارش و شاخص پیمان

## تغییرات این مرحله

### پیشرفت پیمان

- منحنی مالی واقعی از صورت‌وضعیت‌های approved/paid غیرلغوشده و همان محاسبهٔ پیشرفت مالی ساخته می‌شود. صورت‌وضعیت لغوشده در پیشرفت فیزیکی نیز وارد نمی‌شود.
- عکس پیشرفت فیزیکی به‌عنوان «برنامه» استفاده نمی‌شود. چون برنامهٔ مبنای مستقل پیمان به این نما متصل نیست، API مقدار برنامه و انحراف را null می‌دهد، خط برنامه ترسیم نمی‌شود و نبود مبنا صریح اعلام می‌شود. هیچ برنامهٔ جایگزین یا دادهٔ نمونه تولید نشده است.
- خطای API، نبود منبع اندازه‌گیری و مقدار واقعی صفر از یکدیگر متمایزند؛ در خطای دریافت، درصد و کارت‌های صفر نمایش داده نمی‌شوند و بازخوانی فراهم است.
- تفکیک ردیف‌ها، ثبت و تأیید نقاط عطف و انتخاب ثابت پیمان حفظ شده‌اند.

### گزارش‌های پیمان

- گزارش پیشرفت/مدیریتی همان ورودی معتبر صفحهٔ پیشرفت (مبلغ پیمان، نوع، سقف، BOQ، کارکرد، صورت‌وضعیت و مراحل) را مصرف می‌کند.
- نگاشت فاصله و مصرف سقف از خروجی تو‌در‌توی موتور اصلاح شد؛ منحنی گزارش نیز همان تابع مشترک منحنی صفحه است.
- نبود مبنا در خروجی گزارش اعلام می‌شود، نه اینکه برنامهٔ صفر چاپ شود. فاصلهٔ نامعتبر با «—» نمایش داده می‌شود.
- فرم سربرگ همهٔ فیلدهای لازم برای سند رسمی را دارد: نام و کد واقعی پروژه، طرف‌ها و نشان‌های متنی، شماره/نسخه، تهیه/تأییدکننده و توزیع. نام و کد پروژه از زمینهٔ واقعی پروژه پیش‌پر می‌شود و قابل اصلاح است؛ نام پیمان دیگر جای نام پروژه جا زده نمی‌شود.
- سربرگ رسمی مقدار جایگزین «—» را به‌عنوان اطلاعات معتبر قبول نمی‌کند. مجوز صدور رسمی در سرور حفظ شده است.
- نام گزارش در پیش‌نمایش از عنوان فارسی خوانده می‌شود. با تغییر گزارش، مخاطب، پیمان یا سربرگ، پیش‌نمایش قبلی پاک و پاسخ دیررس کنار گذاشته می‌شود.
- چاپ/PDF همچنان HTML قابل چاپ مرورگر است، نه فایل PDF تولیدشده در سرور؛ پنجره در همان کلیک باز می‌شود تا پس از fetch مسدود نشود. ورد/اکسل/CSV حفظ شده‌اند.

### شاخص‌ها و هشدار زودهنگام

- آستانهٔ سفارشی و خاموش‌بودن قاعده هم در هشدار فعال و هم در «در مسیر هشدار» اعمال می‌شود. عبور پیش‌بینی‌شده از حد پایین نیز مستقل از جهت کلی سنجه بررسی می‌شود.
- فاصلهٔ فیزیکی–مالیِ نامعتبر از سنجه، نمرهٔ سلامت و هشدار مبتنی بر فاصله کنار گذاشته می‌شود. نبود BOQ/مراحل یا مبلغ مبنا، مجوز قضاوت اضافه‌پرداخت نیست.
- شمارش ضمانت‌نامه از ساختار صحیح `state` خوانده می‌شود؛ آزادشده‌ها جزء وثیقهٔ باز یا رو به انقضا نیستند. تعداد رو به انقضا هم در عکس و هم روند ذخیره/خوانده می‌شود.
- خطای خواندن دفاتر یا قواعد دیگر به آرایهٔ خالی تبدیل نمی‌شود؛ رابط خطا را به‌جای صفر هشدار نشان می‌دهد.
- عکس وضعیت فعلی فقط برای **ماه جاری میلادی UTC، قالب YYYY-MM** قابل ثبت است؛ این API بازسازی تاریخی انجام نمی‌دهد. ماه گذشته/آینده/برچسب دلخواه پذیرفته نیست.
- به‌روزرسانی عکس جاری نیازمند RowVersion فعلی است، تراکنش و AuditLog قبل/بعد دارد و تداخل 409 می‌دهد. کلیک تکراری در رابط مهار می‌شود. داده‌های تاریخی کاربر بازنویسی یا حذف نشده‌اند؛ برای سوابق فاقد کنترل جدید، اخطار بررسی اعتبار نمایش داده می‌شود.
- تغییر قواعد ممیزی می‌شود. فیلدهای ارسال‌نشده، آستانه/شدت/وضعیت قبلی را بی‌صدا به پیش‌فرض بازنمی‌گردانند.
- مجوز ثبت عکس و تغییر قواعد در رابط از پاسخ معتبر سرور دریافت می‌شود. مسیرهای این سه بخش پیش از خواندن داده/صدور خروجی، دسترسی پروژه را بررسی می‌کنند؛ 403 مستقل از وجود یا نبود شناسهٔ پیمان است.
- نوشتن عمومی در ContractMetricsSnapshot و ContractAlertRule مسدود و مسیر اختصاصی اجباری است.

## ماندگاری و استقرار

دو ستون nullable افزوده شد: `ContractMetricsSnapshot.ExpiringGuaranteeCount` و `IsGapReliable`. مهاجرت ثبت‌شدهٔ 0077 و اسکریپت `db/mssql/V007__contract_snapshot_quality.sql` افزایشی‌اند؛ FK فیزیکی و بازنویسی سابقه ندارند. SQL Server در این محیط در دسترس نیست و مهاجرت SQL اجرا نشده است.

باندل‌های موتور مطابق الگوی مخزن با `npm run build:cnt`, `build:sql`, `build:rpt` بازتولید می‌شوند.

## اعتبارسنجی

- ۳۷۴ تست متمرکز: پیشرفت، KPI، گزارش، آزمون‌های جدید صحت و رگرسیون امتیازدهی، تغییرات، الحاقیه، فرم‌ها و فضای صورت‌وضعیت.
- تست جدید دامنه: قواعد سفارشی/خاموش، آستانهٔ پایین، روند انقضا، دورهٔ جاری، منحنی بدون مبنای ساختگی و همسانی گزارش.
- تست جدید REST: دادهٔ موقت واقعی، حذف IPC لغوشده از محاسبه، نبود اثر عکس واقعی بر برنامه، کنترل پروژه/نقش، نمره و هشدار بدون فاصلهٔ نامعتبر، نسخهٔ عکس و تداخل، ممیزی تنظیم قواعد و خروجی رسمی کامل.
- مرورگر با دادهٔ موقت در ۱۴۴۰×۹۰۰ و ۱۲۸۰×۸۰۰: خطای تزریق‌شده به پیشرفت و قواعد بدون صفر ساختگی، عکس جاری، پیش‌نمایش صحیح، سربرگ رسمی و خروجی Word و زبانهٔ چاپ، اسکرول داخلی و بدون اسکرول بیرونی.
- جداسازی مقصدهای سایدبار، حفظ انتخاب پیمان و قالب‌های صورت‌وضعیت مجدداً بررسی شد. هیچ ثبت آزمایشی روی دادهٔ کسب‌وکار کاربر انجام نشده است.
