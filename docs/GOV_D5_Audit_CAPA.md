# GOV D5 — ممیزی، عدم‌انطباق و CAPA

خلاصه ۳ خط: امتیاز انطباق **وزنی** محاسبه می‌شود (۰..۱۰۰) و باند Green ≥۹۰ / Yellow ≥۷۵ / Red <۷۵ دارد. هر یافته Major/Critical بدون CAPA، بستن برنامه ممیزی را مسدود می‌کند. یافته و CAPA هر دو در زنجیره append-only ثبت می‌شوند.

## ۱) فرمول

```
score = Σ(compliance_i × weight_i) / Σ(weight_i)   (گرد به عدد صحیح)
band  = score ≥ 90 → Green | ≥ 75 → Yellow | else Red
```
بدون یافته → ۱۰۰٪ (ممیزی انجام‌نشده با ۱۰۰ اشتباه گرفته نشود؛ وضعیت `draft` جدا نمایش داده می‌شود).

## ۲) شدت و CAPA

| شدت | تعریف | CAPA |
|---|---|---|
| `minor` | انحراف مستندی بدون اثر بر تحویل | اختیاری |
| `major` | انحراف فرآیندی با اثر بر زمان/هزینه/کیفیت | **الزامی** |
| `critical` | نقض ایمنی/قرارداد/قانون | **الزامی + تشدید L2 به بالا** |

پیش‌فرض وقتی شدت اعلام نشده: `compliance < 75 → major` وگرنه `minor`.

## ۳) دروازه بستن ممیزی
`auditCloseBlocked(findings) = any(severity ∈ {major, critical} AND capa_id IS NULL)`
در UI به‌صورت بنر قرمز بالای تب «ممیزی» نمایش داده می‌شود؛ در دیتابیس با تریگر `BEFORE UPDATE` روی `gov_audit_plan`.

## ۴) چرخه CAPA
`باز → اقدام تعیین‌شده (مالک + مهلت) → اجرا → راستی‌آزمایی → بسته`
تأخیر CAPA از مهلت → همان نردبان تشدید D3.

## ۵) چک‌لیست استانداردها (پایه seed)
PMBOK 7th (کنترل یکپارچه تغییرات، حاکمیت، ذی‌نفعان) · ISO 9001 (کنترل مدارک، اقدام اصلاحی) · ISO 45001 (HSE کارگاه) · رویه داخلی PMO (گزارش‌دهی، Baseline، دروازه ادعا).

## ۶) تست‌های پذیرش (پیاده‌شده)
`complianceScore([90,70]) = 80` · وزنی `[90×3, 70×1] = 85` · باندها ✔ · یافته ۶۰٪ بدون CAPA → بلاک ✔ · با CAPA → آزاد ✔
