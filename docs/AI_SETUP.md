# راه‌اندازی ترجمهٔ قرارداد روی سرور شما

این سند فقط یک موضوع دارد: چرا ترجمه در محیط پیش‌نمایش کار نمی‌کند و
چه چیزی روی سرور خودتان لازم است.

---

## خلاصه در یک خط

کد ترجمه سالم و آزموده است؛ محیط پیش‌نمایش **دسترسی اینترنت خروجی
ندارد**، پس هیچ سرویس هوش مصنوعی از آنجا پاسخ نمی‌دهد.

---

## آنچه بدون اینترنت کار می‌کند

| قابلیت | وضعیت آفلاین |
|---|---|
| بارگذاری قرارداد (PDF / DOCX / TXT) | ✅ کار می‌کند |
| استخراج متن از فایل | ✅ کار می‌کند |
| **استخراج ساختار شکست (WBS)** | ✅ کار می‌کند — موتور قاعده‌محور محلی |
| فرمان‌های درخت (هرس سطح، شماره‌گذاری، حذف شاخه) | ✅ کار می‌کند |
| خروجی اکسل / XER / MS Project XML | ✅ کار می‌کند |
| **ترجمهٔ تخصصی** | ❌ به اینترنت و کلید نیاز دارد |
| فرمان آزاد به هوش مصنوعی | ❌ به اینترنت و کلید نیاز دارد |

نکتهٔ مهم: استخراج WBS به هوش مصنوعی **نیاز ندارد**. موتور قاعده‌محور
بندها را از متن تشخیص می‌دهد و درخت را می‌سازد. هوش مصنوعی فقط کیفیت
گروه‌بندی را بالا می‌برد.

---

## آزمونی که انجام شد

```bash
curl -o /dev/null -w "%{http_code}" https://api.deepseek.com   # → 000
curl -o /dev/null -w "%{http_code}" https://api.openai.com     # → 000
```

کد `000` یعنی اتصال اصلاً برقرار نشد — نه خطای کلید، نه خطای سرویس.

سپس یک سرویس ساختگی محلی (`server/fakeAi.mjs`) اجرا شد و همان درخواست
از همان مسیر فرستاده شد:

```json
{"ok":true,"data":{"translated":"[ترجمهٔ آزمایشی] Article 1 - Definitions.","provider":"deepseek"}}
```

یعنی زنجیرهٔ رابط ← سرور ← لایهٔ ارائه‌دهنده ← ساخت درخواست ← خواندن
پاسخ ← نمایش، کامل سالم است.

---

## راه‌اندازی روی سرور خودتان

### ۱. ساخت و اجرا

```bash
npm install
npm run build:ai && npm run build:clause && npm run build:ogw
npx vite build

PORT=4000 PERSIST_DRIVER=json DATA_DIR=./server/rundata node server/index.js
node server/preview.mjs        # رابط کاربری روی ۵۱۷۳
```

### ۲. تنظیم سرویس هوش مصنوعی

در برنامه: **مدیریت سامانه ← ۵. هوش مصنوعی و یکپارچگی**

| میدان | مقدار |
|---|---|
| سرویس‌دهنده | `DeepSeek AI` یا `OpenAI` |
| شناسهٔ مدل | `deepseek-chat` یا `gpt-4.1-mini` |
| کلید دسترسی | کلید واقعی شما |

**مهم:** گزینهٔ «شبیه‌سازی‌شده» ترجمه نمی‌کند — آن موتور قاعده‌محور
آفلاین است.

### ۳. جایگزین: کلید در محیط سرور

اگر نمی‌خواهید کلید در رابط کاربری وارد شود:

```bash
AI_API_KEY=sk-xxxx \
AI_MODEL=deepseek-chat \
AI_RESPONSES_URL=https://api.deepseek.com/chat/completions \
PORT=4000 PERSIST_DRIVER=json DATA_DIR=./server/rundata node server/index.js
```

کلید در پایگاه داده و سیاههٔ ممیزی نوشته نمی‌شود؛ فقط در همان فراخوانی
مصرف می‌شود.

## عیب‌یابی

پیام‌های خطا عمداً از هم تفکیک شده‌اند تا بدانید کدام حلقه شکسته است:

| پیام | معنا | راه حل |
|---|---|---|
| `E-AI-UNREACHABLE` | سرور به اینترنت یا به آن آدرس نمی‌رسد | فایروال، پروکسی یا DNS سرور |
| `E-AI-NO-SECRET` | کلید وارد نشده | مدیریت سامانه ← کلید دسترسی |
| `E-AI-AUTH` (۴۰۱) | کلید رد شد | کلید اشتباه یا منقضی |
| `E-AI-ARENA-NO-SESSION` | Arena نشست ندارد | فعلاً DeepSeek یا OpenAI |
| «موتور قاعده‌محور ترجمه نمی‌کند» | سرویس روی حالت شبیه‌سازی است | سرویس واقعی انتخاب کنید |

### آزمون سریع بدون رابط کاربری

```bash
curl -X POST localhost:4000/api/ai/run \
  -H 'content-type: application/json' \
  -H 'x-ai-key: sk-xxxx' \
  -d '{"prompt":"translate","context":{"provider":"deepseek","targetLang":"fa","text":"Article 1 - Definitions."}}'
```

پاسخ درست: `{"ok":true,"data":{"translated":"ماده ۱ — تعاریف..."}}`

---

## آزمون محلی بدون اینترنت

برای دیدن رفتار رابط کاربری بدون سرویس واقعی:

```bash
node server/fakeAi.mjs &          # روی ۴۱۱۱

AI_RESPONSES_URL=http://127.0.0.1:4111/v1/chat \
PORT=4000 PERSIST_DRIVER=json DATA_DIR=./server/rundata node server/index.js
```

سپس در برنامه DeepSeek را انتخاب کنید و هر کلیدی بگذارید. ترجمه با
پیشوند `[ترجمهٔ آزمایشی]` برمی‌گردد.

این سرویس **فقط برای عیب‌یابی** است و در محیط عملیاتی اجرا نمی‌شود.

---

## دو قید که در کد اعمال شده

**۱. متن اصلی هرگز جایگزین نمی‌شود.** در دعوای قراردادی مرجع نسخهٔ
امضاشده است، نه ترجمه. هر دو نگه داشته می‌شوند و ترجمه فقط‌خواندنی است.

**۲. مترجم اجازهٔ تغییر عدد ندارد.** دستور سامانه‌ای صریح می‌گوید عدد،
تاریخ، شمارهٔ بند و واحد باید عیناً کپی شوند و هیچ جمله‌ای خلاصه نشود —
بند خلاصه‌شده یعنی تعهد حذف‌شده.

---

## واژگان تخصصی

۳۵ اصطلاح نفت و گاز پیش از ارسال به مدل تزریق می‌شود
(`src/services/ogWbs.ts`)، چون مترجم عمومی `tie-in` را «گره خوردن» و
`workover` را «اضافه‌کاری» ترجمه می‌کند.

برای افزودن اصطلاح، به `OG_GLOSSARY` اضافه کنید؛ آزمون یکتایی معادل‌ها
جلوی دو ترجمهٔ متفاوت برای یک اصطلاح را می‌گیرد.
