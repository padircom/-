| Loop | حکم | شواهد |

## ماتریس تطبیق بین‌بخشی

| پرسش | پاسخ |
|---|---|
| D2 ↔ D10 API یکسان؟ | بله — نام موجودیت‌ها و enumها منطبق است |
| موتور ↔ UI یکسان؟ | بله — UI مستقیماً `src/services/governance.ts` را صدا می‌زند |
| موتور TS ↔ موتور Node؟ | همان الگوریتم، دو زبان؛ تست‌ها روی نسخه Node |
| Baseline محفوظ؟ | بله — `baseline_rewrite_without_cr` در دروازه |
| نام‌های SQL قدیمی حفظ؟ | بله — از طریق VIEW پس از کپی داده |
| آیتم جدید در سایدبار اصلی؟ | خیر — زیرفرایندهای اضافه فقط داخل صفحه d6 |

## ۳) نتیجه

**دامنهٔ طراحی و منطق ماژول حاکمیت (d6) بسته شد:** ۱۰ تحویل‌شدنی + OpenAPI + موتور قواعد با ۱۲ تست سبز + صفحهٔ کاربری پنج‌تبی متصل به سایدبار داخلی، بدون کوچک‌ترین تغییر در سایدبار اصلی، فونت Vazirmatn و `src/index.css`.

باقیمانده تا «عملیاتی روی داده واقعی» در جدول شکاف بالا فهرست و برآورد شده است.
