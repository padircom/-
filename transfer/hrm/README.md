## یک فایل، یک دستور

`HRM_COMPLETE.diff` (۶٫۸ MB) کل کار را در یک تغییر دارد.

نسخهٔ چند-کامیتی (`git format-patch`) عمداً حذف شد: پس از تمیزکاری
مخزن، آن patchها **خودِ بایگانی حذف‌شده** را هم حمل می‌کردند و به ۵۰
مگابایت می‌رسیدند — یعنی برای رساندن حذف یک فایل، خود فایل را
می‌فرستادند. تاریخچهٔ کامیت‌ها در خودِ مخزن محفوظ است.

## اعمال

```bash
cd <مخزن>
git checkout -b hrm-d8-d13 0831340
git apply --check /مسیر/HRM_COMPLETE.diff   # آزمایش خشک
git apply /مسیر/HRM_COMPLETE.diff
git add -A && git commit -m "HRM D8–D13 + تمیزکاری مخزن"
```

> diff با `--binary` ساخته شده چون حذف چند فایل باینری را حمل می‌کند.
> بدون آن `git apply` با «cannot apply binary patch» رد می‌کرد.
